# Sbewo — обновление дизайна по 13 экранам (v6)

Это **обновление фронтенда существующего `sbewo-frontend`**, не новый бэкенд.

## Установка
1. Открой GitHub → `sbewo-frontend`.
2. Из этого архива **замени только** файлы в корне `index.html`, `app.js`, `style.css`.
3. В папке `assets/mascot/` обнови (или сохрани) 12 файлов `kyu-*.webp`. Важно: нужно сохранить вложенную структуру `assets/mascot/`, а не поместить изображения в корень.
4. Текущий `config.js` **НЕ трогай**. Он уже содержит правильный адрес Render `https://sbewo-backend.onrender.com` и твой username бота. `config.example.js` — только образец.
5. `Commit changes` → GitHub `Actions` → дождись успешной публикации Pages. Открой Telegram Mini App заново. Для сброса кеша можно открыть URL Pages с `?v=6`.
6. Для проверки первого знакомства используй новый профиль/очистку данных сайта или в DevTools `window.SbewoDev.resetIntro()`. Версия онбординга обновлена с ключом `sbewo-v6-onboarded`, поэтому должна появиться один раз и у пользователей старой v5.

## Реальные ограничения
- Telegram Business API выдаёт только разрешённые новые события; нельзя восстановить старые сообщения.
- На сервере **нет** сохранения файлов медиа, отслеживания удалений в группах, push-уведомлений, оплаты Pro. На соответствующих страницах нет ложных обещаний работоспособности.
- Используемые прозрачные иллюстрации Кью — подготовленные ранее WebP в том же стиле, но **не оригинальные слои из исходного референса**.
- 13 исходных кропов крайне низкого разрешения (~160–200 px по ширине). Поэтому обновление приближает композицию, но не гарантирует pixel-perfect совпадения каждой детали.
- Тестировались DOM-рендеринг, маршруты, основные элементы и горизонтальная прокрутка на ширинах 320/375/390/430 CSS px в Chromium. Реальный Telegram iOS/Android и опубликованный GitHub Pages после установки не тестировались.
