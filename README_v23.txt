Sbewo v23 — компактная нижняя панель

Изменения:
- Панель Главная / Чаты / Настройки уменьшена по высоте.
- Сохранены цвета и иконки Telegram Blue из v22.
- Под панелью полностью непрозрачная подложка: скроллируемые карточки и текст не просвечивают.
- Страницы и логика API без изменений.

Установка:
1. В репозитории фронтенда GitHub Pages замените style.css и index.html файлами из архива.
2. Не меняйте рабочий config.js и сервер Render.
3. Сделайте Commit и после публикации повторно откройте Mini App в Telegram.

Проверка: Chromium на ширинах 320, 390 и 430 px; ошибок JavaScript и горизонтального переполнения нет.
