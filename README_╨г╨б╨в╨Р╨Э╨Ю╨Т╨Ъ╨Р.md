# Sbewo v19 — фронтенд (GitHub Pages)

Важное: v19 требует одновременного обновления сервера Render. Если обновить только фронтенд, настройки полного архива и новые аватары/медиа не заработают.

## Куда что положить

В **репозитории фронтенда** (GitHub Pages) замените в корне:
- `index.html`
- `app.js`
- `style.css`

Оставьте **свой** рабочий `config.js` без изменений. В ZIP его нет, там только `config.example.js` (пример). Не загружайте секреты бота в GitHub Pages.

Сохраните прежние дополнительные файлы и каталог `assets`, если они уже есть. Кью встроен в `app.js`, поэтому исчезновения маскота из-за отдельной папки быть не должно.

Сделайте Commit. Убедитесь, что GitHub Pages показал успешный деплой. Полностью закройте и снова откройте Mini App. Версия файлов в `index.html` — `v=19.0`.

## Обновлённая навигация

- Главная: содержимое v18 не менялось (профиль, статус и события).
- Чаты: только чаты с событиями, поиск, фильтр избранного; внутри фильтры удаления/правки/медиа/избранное; действие с заметками и звёздочкой через подробности события.
- Настройки: подключение, уведомления, приватность, включение полного архива и информационная Pro-карточка.

## Важные пределы

- При выключенном полном архиве сервер хранит обычные сообщения в зашифрованном буфере максимум 48 часов: иначе нельзя показать текст, если его удалят. В постоянной выдаче видны только удаления и правки. Старые сообщения, которые удалят после очистки буфера, нельзя восстановить.
- При включённом полном архиве обычные сообщения тоже появляются в выдаче; параметр сохраняется на сервере.
- Медиа сохраняется в PostgreSQL, только если Telegram передал файл и он не превышает `MAX_MEDIA_BYTES` (по умолчанию 6 МБ). Большое видео и защищённый контент могут быть недоступны.
- В Telegram не всегда можно получить аватар другого человека. Попытка выполняется через официальный `getUserProfilePhotos`; если фотографии нет или доступ закрыт, показываются инициалы.
- Sbewo Pro здесь — информационная карточка, без платежей или фальшивого тарифа.
- Групповые удаления пока не реализованы сервером.

## Проверки

Локальные тесты выполнены на 320/390/430 px, включая вкладки, события, избранное, заметки, отсутствие горизонтального переполнения и JS-ошибок. Работа реального webhook и доступ к аватарам/файлам Telegram зависят от разрешений и требуют проверки уже после публикации.
